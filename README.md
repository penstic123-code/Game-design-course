# 游戏设计互动课

一门从零开始的游戏设计课，做成 29 个互动网页：不用装任何东西，双击 `index.html` 就能读。目标读者是想系统学会游戏设计的普通人，不要求任何基础。

每一章都从一个具体的小处境讲起，讲清楚一个概念为什么会被发明出来，再让读者亲手拆、拼、调一个小实验，最后才给概念起名字。全课没有大段公式和教科书式的定义，但每个原理都标了出处。

## 每章长什么样

- **五层讲法**：是什么 → 发明故事（当年的人遇到什么麻烦、试过什么、为什么不行）→ 为什么成立（底层原理，标出处，附一个能亲手验证的实验）→ 怎么用 → 反思与争议。
- **插图与例子**：每个例子（包括反例）配一张手绘火柴人插图，用横向页签切换；发明故事配带图的时间线。全课约 740 张插图，每张只用一次，全是自己画的 SVG。
- **互动**：每章有一两个像"拆房子"一样的直接操作（拖、调滑块、搭、玩小游戏），每个互动配一条"试试看"任务，完成时给反馈。
- **跨学科原理**：预测误差、损失厌恶、古德哈特定律、囚徒困境、幸存者偏差等，挂在具体现象下，在不同章节反复出现。
- **练习**：每章 4–6 题带解析，至少一题问"为什么"，一题问"为什么被发明"。
- **阅读辅助**：章内目录、分节折叠、阅读进度、笔记自动保存、术语悬停释义。

另有配套页面：学习地图与三条学习路径（`index.html`）、概念关系图（`map.html`，110 个概念、162 条关系）、术语表（`glossary.html`，215 条）、闪卡（`flashcards.html`）。

## 怎么打开

下载或克隆后，用浏览器打开 `index.html` 即可。纯前端、没有构建步骤、没有依赖。

页面会从网上加载两套字体（Google Fonts 的 Ma Shan Zheng、jsDelivr 上的霞鹜文楷）。离线时自动退回系统楷体，内容不受影响。英文字母和数字用的手写字体 Patrick Hand 已放在 `lib/fonts/`（SIL OFL 1.1），登记见 `lib/README.md`。

## 质量检查

每章交付前过三道检查：内联脚本语法检查；用无头浏览器在 420px（手机）和 1100px（桌面）宽度下点击所有按钮、拖动所有滑块，检查 JS 报错、横向溢出，以及图内文字压边框、挤线、超出框；再逐张截图看画面。检查脚本在 `tools/` 里（需要 Node 22+ 和 Windows 上的 Edge；`illus-gallery.html` 是插图图库，用浏览器直接打开）：

```
node tools/qa.mjs <课程文件夹绝对路径> [ch01,ch02]   # 必须传绝对路径
node tools/shot.mjs <html绝对路径> <输出.png> ".egcar@0" 1000
python tools/audit.py .
python tools/build_glossary.py <课程文件夹绝对路径>
```

## 现状与已知问题

- 英文版还没做，页面里的语言切换按钮是隐藏的。
- 事实由 AI 辅助联网核实：能查到原始来源的已标出处，查不到的已删除或改成保守说法。仍有一部分出处（多是论文页码、二手转述）只核对过二手来源，已经在各章的"出处"里按实际情况写明。引用前请回到原文核对。
- 手绘风格的字体和线条在个别窄屏手机上仍可能有细小错位，欢迎提 issue 并附截图。
- 样式里还用 CSS `@import` 加载网络字体，网络很慢时可能延迟首屏。
