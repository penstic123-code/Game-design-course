# 游戏设计互动课

一门从零开始的游戏设计课，做成 29 个互动网页：双击 `index.html` 就能读，不用装任何东西，也不要求任何基础。

每一章先讲一个具体的小处境和其中的麻烦，再讲当年的人怎么想到这个办法，然后让读者亲手拆、拼、调一个小实验，最后才给概念起名字。全课没有大段公式和教科书式的定义，每个原理都标了出处。


## 特点

- **先讲为什么被发明**：每个概念按"是什么 → 发明故事 → 为什么成立 → 怎么用 → 反思"讲，让读者觉得它非有不可。
- **每章都能动手**：拖、调滑块、搭规则、玩小游戏，每个互动配一条"试试看"任务；选择题只放在练习里。
- **插图画出"为什么"**：约 740 张手绘火柴人插图，例子和反例各一张，用横向页签切换；发明故事配带图时间线。
- **底层原理**：预测误差、损失厌恶、古德哈特定律、囚徒困境、幸存者偏差等，挂在具体现象下，在不同章节反复出现。
- **配套**：5 条学习路径、110 个概念的关系图、215 条术语表与闪卡、笔记和进度自动保存。
- **纯前端、离线可用**：无构建步骤，手机和桌面都能读。

## 怎么打开

下载或克隆后，用浏览器打开 `index.html` 即可。纯前端、没有构建步骤、没有依赖。

页面会从网上加载两套字体（Google Fonts 的 Ma Shan Zheng、jsDelivr 上的霞鹜文楷）。离线时自动退回系统楷体，内容不受影响。英文字母和数字用的手写字体 Patrick Hand 已放在 `lib/fonts/`（SIL OFL 1.1），登记见 `lib/README.md`。

## 目录结构

```
index.html        目录页：章节卡片、学习地图、学习路径
map.html          概念关系图        glossary.html  术语表        flashcards.html  闪卡
chNN-xxx.html     29 个章节
css/style.css     共享样式（手绘笔记本风格）
js/common.js      章节表、顶栏、章内导航、进度、测验、笔记、例子轮播、插图装载
js/graph.js       概念关系图数据
js/illus.js       火柴人与通用插图库
js/illus-chNN.js  各章自己的插图包
js/glossary-data.js  术语表与闪卡数据（由脚本从各章生成）
lib/              本地字体
tools/            自动检查与截图脚本、插图图库
项目规则与经验.md   做这门课时总结的画面、内容、形式经验
```

## 质量检查

每章在手机（420px）和桌面（1100px）宽度下自动点遍按钮、拖遍滑块，检查 JS 报错、横向溢出，以及图内文字压边框、挤线、超出框，再逐张截图看画面。脚本在 `tools/`（需要 Node 22+ 和 Windows 的 Edge）：

```
node tools/qa.mjs <课程文件夹绝对路径> [ch01,ch02]   # 必须传绝对路径
node tools/shot.mjs <html绝对路径> <输出.png> ".egcar@0" 1000
python tools/audit.py .
```

## 现状与已知问题

- 英文版还没做，页面里的语言切换按钮是隐藏的。
- 事实由 AI 辅助联网核实：能查到原始来源的已标出处，查不到的已删除或改成保守说法。仍有一部分出处（多是论文页码、二手转述）只核对过二手来源，已经在各章的"出处"里按实际情况写明。引用前请回到原文核对。
- 手绘风格的字体和线条在个别窄屏手机上仍可能有细小错位，欢迎提 issue 并附截图。
- 样式里还用 CSS `@import` 加载网络字体，网络很慢时可能延迟首屏。
